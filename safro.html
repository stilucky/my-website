Testnet · Node Setup
Safrochain
A Cosmos SDK-based testnet blockchain focused on decentralized finance infrastructure.
safro-testnet-1 v0.1.0 Gas: 0.001usaf Port prefix: 42
Step 1
Install Dependencies & Go
sudo apt update && sudo apt upgrade -y
sudo apt-get install git curl build-essential make jq gcc snapd chrony lz4 tmux unzip make bc -y
Install Go 1.23.4 (amd64)
rm -rf $HOME/go && sudo rm -rf /usr/local/go
cd $HOME
curl https://dl.google.com/go/go1.23.4.linux-amd64.tar.gz | sudo tar -C /usr/local -zxvf -
cat <<'EOF' >> $HOME/.bash_profile
export GOROOT=/usr/local/go
export GOPATH=$HOME/go
export GO111MODULE=on
export PATH=$PATH:/usr/local/go/bin:$HOME/go/bin
EOF
source $HOME/.bash_profile
go version
Step 2
Set Variables & Install Binary
echo "export SAFRO_PORT="42"" >> $HOME/.bash_profile
source $HOME/.bash_profile
Build from source (v0.1.0)
cd $HOME
git clone https://github.com/Safrochain-Org/safrochain-node.git
cd safrochain-node
git checkout release/v0.1.0
make install
safrochaind version
Step 3
Configure Node
Initialize & client config
safrochaind init Stilucky-node --chain-id safro-testnet-1
sed -i "s/chain-id = .*/chain-id = \"safro-testnet-1\"/" $HOME/.safrochain/config/client.toml
sed -i "s/keyring-backend = .*/keyring-backend = \"os\"/" $HOME/.safrochain/config/client.toml
sed -i "s/node = .*/node = \"tcp:\/\/localhost:${SAFRO_PORT}657\"/" $HOME/.safrochain/config/client.toml
Custom ports
sed -i.bak -e "s%:1317%:${SAFRO_PORT}317%g;s%:8080%:${SAFRO_PORT}080%g;s%:9090%:${SAFRO_PORT}090%g;s%:9091%:${SAFRO_PORT}091%g;s%:8545%:${SAFRO_PORT}545%g;s%:8546%:${SAFRO_PORT}546%g;s%:6065%:${SAFRO_PORT}065%g" $HOME/.safrochain/config/app.toml
sed -i.bak -e "s%:26658%:${SAFRO_PORT}658%g;s%:26657%:${SAFRO_PORT}657%g;s%:6060%:${SAFRO_PORT}060%g;s%:26656%:${SAFRO_PORT}656%g;s%^external_address = \"\"%external_address = \"$(wget -qO- eth0.me):${SAFRO_PORT}656\"%;s%:26660%:${SAFRO_PORT}660%g" $HOME/.safrochain/config/config.toml
Gas, indexer & pruning
sed -i 's|minimum-gas-prices =.*|minimum-gas-prices = "0.001usaf"|g' $HOME/.safrochain/config/app.toml
sed -i -e "s/^indexer *=.*/indexer = \"null\"/" $HOME/.safrochain/config/config.toml
sed -i -e "s/^pruning *=.*/pruning = \"custom\"/" $HOME/.safrochain/config/app.toml
sed -i -e "s/^pruning-keep-recent *=.*/pruning-keep-recent = \"100\"/" $HOME/.safrochain/config/app.toml
sed -i -e "s/^pruning-interval *=.*/pruning-interval = \"50\"/" $HOME/.safrochain/config/app.toml
Genesis & address book
curl -Ls https://file3.node39.top/Testnet/Safro/genesis.json > $HOME/.safrochain/config/genesis.json
curl -Ls https://file3.node39.top/Testnet/Safro/addrbook.json > $HOME/.safrochain/config/addrbook.json
Step 4
Create Service & Start
sudo tee /etc/systemd/system/safrochaind.service > /dev/null <<EOF
[Unit]
Description=safrochaind Service
After=network-online.target

[Service]
User=$USER
ExecStart=$(which safrochaind) start
Restart=always
RestartSec=3
LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl daemon-reload
sudo systemctl enable safrochaind
sudo systemctl start safrochaind
Check sync status
safrochaind status 2>&1 | jq .SyncInfo
Binary Update
Upgrade Node
Thay NEW_VERSION bằng tag phiên bản mới nhất từ GitHub.
Stop & build new version
sudo systemctl stop safrochaind
cd $HOME
rm -rf safrochain-node
rm -rf $(which safrochaind)
git clone https://github.com/Safrochain-Org/safrochain-node.git
cd safrochain-node
git checkout NEW_VERSION
make install
safrochaind version
Restart & verify
sudo systemctl restart safrochaind
sudo journalctl -u safrochaind -f
