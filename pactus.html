Setup
Installation
Step 1 — Server Preparation
Update system packages and install required dependencies.
# Cập nhật và cài dependencies
sudo apt update && sudo apt upgrade -y && sudo apt install tmux git curl -y && sudo apt install make clang pkg-config libssl-dev build-essential -y
Step 2 — Download Binary
Choose your architecture.
# Tải và giải nén binary Pactus (amd64)
ver="1.13.0" && \
cd $HOME && rm -rf node_pactus && \
wget https://github.com/pactus-project/pactus/releases/download/v${ver}/pactus-cli_${ver}_linux_amd64.tar.gz && \
tar -xzf pactus-cli_${ver}_linux_amd64.tar.gz && \
rm -rf pactus-cli_${ver}_linux_amd64.tar.gz && \
mv pactus-cli_${ver} node_pactus && cd node_pactus
# Tải và giải nén binary Pactus (arm64)
ver="1.13.0" && \
cd $HOME && rm -rf node_pactus && \
wget https://github.com/pactus-project/pactus/releases/download/v${ver}/pactus-cli_${ver}_linux_arm64.tar.gz && \
tar -xzf pactus-cli_${ver}_linux_arm64.tar.gz && \
rm -rf pactus-cli_${ver}_linux_arm64.tar.gz && \
mv pactus-cli_${ver} node_pactus && cd node_pactus
Step 3 — Create / Restore Wallet
Create a new wallet or restore from seed phrase. Save the seed and validator address securely.
# New wallet
./pactus-daemon init

# Restore existing wallet
./pactus-daemon init --restore "<your-seed>"
Step 4 — Sync Blockchain
Remove lock files and data, then import to sync with the network.
# Xóa lock file và dữ liệu cũ
rm -rf $HOME/pactus/.pactus.lock
rm -rf $HOME/pactus/data
cd $HOME/node_pactus
# Đồng bộ dữ liệu blockchain
./pactus-daemon import
Run
Running the Node
# Tạo session tmux và chạy node
tmux new -s pactus
cd $HOME/node_pactus
sudo ./pactus-daemon start
Create environment file with wallet password:
# Tạo file chứa mật khẩu ví
cd $HOME
mkdir -p .env && cd .env
echo "PACTUS_PASSWORD=your-secure-password" > pactusd.env
Create and enable the systemd service:
# Tạo systemd service
sudo tee /etc/systemd/system/pactusd.service > /dev/null <<EOF
[Unit]
Description=Pactus Node
After=network-online.target
StartLimitIntervalSec=0

[Service]
User=$USER
EnvironmentFile=$HOME/.env/pactusd.env
ExecStart=/root/node_pactus/pactus-daemon start -w /root/pactus --password "$PACTUS_PASSWORD"
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF
# Reload daemon
sudo systemctl daemon-reload
# Bật auto-start
sudo systemctl enable pactusd
# Khởi động node
sudo systemctl start pactusd
Operations
Wallet & Validator Commands
Service management
Xem log node
sudo journalctl -u pactusd -f

sudo systemctl start pactusd

Wallet
Xem tất cả địa chỉ, số dư và stake trong ví
cd $HOME/node_pactus && ./pactus-wallet address all --balance --stake
Kiểm tra số dư của một địa chỉ
cd $HOME/node_pactus && ./pactus-wallet address balance <ADDRESS>
Lấy public key của một địa chỉ
cd $HOME/node_pactus && ./pactus-wallet address pub <ADDRESS>
Lấy private key của một địa chỉ — giữ bí mật
cd $HOME/node_pactus && ./pactus-wallet address priv <ADDRESS>
Xem seed phrase (mnemonic) — giữ bí mật
cd $HOME/node_pactus && ./pactus-wallet seed
Đổi mật khẩu ví
cd $HOME/node_pactus && ./pactus-wallet password
Tạo địa chỉ account mới
cd $HOME/node_pactus && ./pactus-wallet address new
Tạo địa chỉ validator mới
cd $HOME/node_pactus && ./pactus-wallet address new --type validator
Transactions
Stake token vào validator (bond) — lần đầu cần thêm --pub <PUBLIC_KEY>
cd $HOME/node_pactus && ./pactus-wallet send bond <FROM> <VALIDATOR_ADDRESS> <AMOUNT>
Bond lần đầu — kèm public key của validator
cd $HOME/node_pactus && ./pactus-wallet send bond --pub <PUBLIC_KEY> <FROM> <VALIDATOR_ADDRESS> <AMOUNT>
Hủy stake khỏi validator (unbond)
cd $HOME/node_pactus && ./pactus-wallet send unbond <VALIDATOR_ADDRESS>
Rút phần thưởng từ validator về ví (withdraw)
cd $HOME/node_pactus && ./pactus-wallet send withdraw <VALIDATOR_ADDRESS> <TO> <AMOUNT>
Chuyển token sang địa chỉ khác (transfer)
cd $HOME/node_pactus && ./pactus-wallet send transfer <FROM> <TO> <AMOUNT>
