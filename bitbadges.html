Mainnet · Node Setup
BitBadges
A multi-chain badges and credentials platform built on Cosmos SDK.
bitbadges-1 v27 Gas: 0.025ubadge Port prefix: 38
Step 1
Install Dependencies & Go
# Cập nhật hệ thống
sudo apt update && sudo apt upgrade -y
# Cài dependencies
sudo apt-get install git curl build-essential make jq gcc snapd chrony lz4 tmux unzip make bc -y
Install Go 1.24.6 (amd64)
# Xóa Go cũ
sudo rm -rf $HOME/go && sudo rm -rf /usr/local/go
cd $HOME
# Tải và giải nén Go 1.24.6
curl https://dl.google.com/go/go1.24.6.linux-amd64.tar.gz | sudo tar -C /usr/local -zxvf -
# Thêm Go vào PATH
cat <<'EOF' >> $HOME/.bashrc
export GOROOT=/usr/local/go
export GOPATH=$HOME/go
export PATH=$PATH:/usr/local/go/bin:$HOME/go/bin
export GOPROXY=https://proxy.golang.org.direct
EOF
# Áp dụng biến môi trường
source $HOME/.bashrc
# Kiểm tra phiên bản Go
go version
Step 2
Set Variables & Install Binary
# Đặt prefix cổng
echo "export BITBADGES_PORT="38"" >> $HOME/.bash_profile
# Áp dụng biến
source $HOME/.bash_profile
Build from source (v27)
cd $HOME
rm -rf bitbadgeschain
# Clone source code
git clone https://github.com/BitBadges/bitbadgeschain.git
cd bitbadgeschain
# Chuyển sang phiên bản v27
git checkout v27
# Biên dịch binary
make build-linux/amd64
sudo mv build/bitbadgeschain-linux-amd64 $HOME/go/bin/bitbadgeschaind
# Xác nhận phiên bản mới
bitbadgeschaind version
Step 3
Configure Node
Initialize & client config
# Khởi tạo node
bitbadgeschaind init Stilucky-node --chain-id bitbadges-1
# Ghi chain-id vào config
sed -i "s/chain-id = .*/chain-id = \"bitbadges-1\"/" $HOME/.bitbadgeschain/config/client.toml
# Đặt keyring backend
sed -i "s/keyring-backend = .*/keyring-backend = \"os\"/" $HOME/.bitbadgeschain/config/client.toml
# Trỏ RPC về cổng tùy chỉnh
sed -i "s/node = .*/node = \"tcp:\/\/localhost:${BITBADGES_PORT}657\"/" $HOME/.bitbadgeschain/config/client.toml
sed -i '/^timeout_commit =/c timeout_commit = "2s"' ${HOME}/.bitbadgeschain/config/config.toml
Custom ports
# Đổi cổng REST/gRPC (app.toml)
sed -i.bak -e "s%:1317%:${BITBADGES_PORT}317%g;s%:8080%:${BITBADGES_PORT}080%g;s%:9090%:${BITBADGES_PORT}090%g;s%:9091%:${BITBADGES_PORT}091%g;s%:8545%:${BITBADGES_PORT}545%g;s%:8546%:${BITBADGES_PORT}546%g;s%:6065%:${BITBADGES_PORT}065%g" $HOME/.bitbadgeschain/config/app.toml
# Đổi cổng P2P/RPC (config.toml)
sed -i.bak -e "s%:26658%:${BITBADGES_PORT}658%g;s%:26657%:${BITBADGES_PORT}657%g;s%:6060%:${BITBADGES_PORT}060%g;s%:26656%:${BITBADGES_PORT}656%g;s%^external_address = \"\"%external_address = \"$(wget -qO- eth0.me):${BITBADGES_PORT}656\"%;s%:26660%:${BITBADGES_PORT}660%g" $HOME/.bitbadgeschain/config/config.toml
Gas, indexer & pruning
# Gas tối thiểu
sed -i "s/minimum-gas-prices = .*/minimum-gas-prices = \"0.025ubadge\"/" $HOME/.bitbadgeschain/config/app.toml
# Tắt indexer
sed -i -e "s/^indexer *=.*/indexer = \"null\"/" $HOME/.bitbadgeschain/config/config.toml

# Pruning mỗi 50 block
sed -i -e "s/^pruning-interval *=.*/pruning-interval = \"50\"/" $HOME/.bitbadgeschain/config/app.toml
Genesis & address book

# Tải addrbook.json
curl -Ls https://file3.node39.top/Mainnet/Bitbadges/addrbook.json > $HOME/.bitbadgeschain/config/addrbook.json

Step 4
Create Service & Start
# Tạo systemd service
sudo tee /etc/systemd/system/bitbadgeschaind.service > /dev/null <<EOF
[Unit]
Description=Bitbadges Node
After=network-online.target

[Service]
User=$USER
WorkingDirectory=$HOME
ExecStart=$(which bitbadgeschaind) start
Restart=always
RestartSec=3
LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
EOF
# Reload daemon
sudo systemctl daemon-reload
# Bật auto-start
sudo systemctl enable bitbadgeschaind
# Khởi động node
sudo systemctl start bitbadgeschaind
Check sync status
# catching_up=false → đã sync xong
bitbadgeschaind status 2>&1 | jq .SyncInfo

Upgrade Node
Kiểm tra phiên bản mới nhất trên GitHub trước khi upgrade. Thay NEW_VERSION bằng tag cần nâng.
Stop & build new version

sudo systemctl stop bitbadgeschaind
cd $HOME/bitbadgeschain
# Lấy code mới nhất
git pull
# Chuyển phiên bản mới
git checkout NEW_VERSION
# Biên dịch binary
make build-linux/amd64
sudo mv build/bitbadgeschain-linux-amd64 $HOME/go/bin/bitbadgeschaind
# Xác nhận phiên bản mới

Restart & verify

sudo systemctl restart bitbadgeschaind
# Xem log realtime

Wallet

# Khôi phục ví từ mnemonic
bitbadgeschaind keys add <wallet> --recover
# Xem danh sách ví

# Kiểm tra số dư

Validator
# Tạo validator
bitbadgeschaind tx staking create-validator validator.json --from <wallet> --chain-id bitbadges-1 --gas auto --gas-adjustment 1.5 --fees 500ubadge -y
# Delegate token
bitbadgeschaind tx staking delegate <valoper> <amount>ubadge --from <wallet> --chain-id bitbadges-1 --fees 500ubadge -y
# Rút phần thưởng
bitbadgeschaind tx distribution withdraw-rewards <valoper> --from <wallet> --chain-id bitbadges-1 --fees 500ubadge -y
# Gỡ jailed validator
bitbadgeschaind tx slashing unjail --from <wallet> --chain-id bitbadges-1 --fees 500ubadge -y
# Bỏ phiếu governance
bitbadgeschaind tx gov vote <id> yes --from <wallet> --chain-id bitbadges-1 --fees 500ubadge -y
