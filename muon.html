Mainnet · Node Setup
Muon Network
A decentralized oracle network enabling trustless cross-chain data access via Docker-based PION nodes.
PION Node Docker-based Port: 8012 / 9012 4 CPU · 8 GB RAM · 40 GB
Step 1
Install Dependencies & Docker
sudo apt-get update && apt-get upgrade -y
sudo apt-get install ca-certificates curl gnupg -y
Install Docker
sudo install -m 0755 -d /etc/apt/keyring
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin -y
Step 2
Deploy Muon Node
curl -o docker-compose.yml https://raw.githubusercontent.com/muon-protocol/muon-node-js/pion/docker-compose-pull.yml
docker compose pull
docker compose up -d
Verify node is running (wait ~5 minutes)
curl http://localhost:8012/status
Step 3
Backup Keys
Backup your keys immediately after deployment. Store the backup.json in a safe location.
docker exec -it muon-node ./node_modules/.bin/ts-node ./src/cmd/index.ts keys backup > backup.json
cat backup.json
Docker Update
Update Node
Pull latest image & restart
docker compose pull
docker compose down
docker compose up -d
Verify after update
curl http://localhost:8012/status
